Call Lightning

Requirements:

  • Spell: 20 CS, (10 Evocation | 20 Conjuration | 50 Transmutation)

Unlock Cost:

  • 20 XP

Tags:

  • Offense
  • Ranged, Flow Sphere AOE, Electric Damage
  • Main-Action + Bonus-Action / Free-Action

Description

When using this Ability, you are put in Call Lightning Stance.
For each time you Enter this Stance, gain a 1 Stack.
On Trigger you shoot out the Lightning Bolts, their Starting Positions can be offset by up to the Ability's Range, to a Pinpointed location.
Max Stacks Count: 3

Multiple Lightning:

  • Call down 1 + Stacks Seperate Lightning Bolts onto Different Targets.
  • Each Bolt is its own Ranged Attack, Roll only a Single Attack, but seperate Damage.
  • Using an On-Attack will Apply to all Lightning Bolts.
  • Electric Damage: 2d6 × ESS

Single Lightning:

  • Call down a Single Strong Bolt of Lightning, this is a Flow Sphere AOE Ranged Attack.
  • Using an On-Attack can Apply to 1 + Stacks Targets, rather than just one.
  • Electric Damage: (2 × Stack)d6 × ESS
  • Radius: ESS^(1/3)

Electric Effect:

  • Against Soaked or Airborn Targets, this Ability Deals Max-Damage.

The Stance Breaks when: Using Abilities, Moving, HD Decrease, Taking Damage
