Description

When using this Ability, you are put in Wind Up Punch Stance.
While in Wind Up Punch Stance, you hold a Charged up Natural Melee Weapon Attack.
Each time you enter this Stance you gain a Stack.
On Stance Trigger: You Move MS × Stack meters, and Attack an Entity whithin Reach.
MAX Stack Count: 3

The Stance Breaks when: Using Abilities
